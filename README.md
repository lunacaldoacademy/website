# ルナカルドアカデミー 公式サイト

キッズプログラミングスクール「ルナカルドアカデミー」（堺美原校・富田林喜志校）の公式ホームページ。
1ページ完結、**黒基調**のデザインで、2026年版の二つ折りパンフレットの内容とトーンに合わせています。
ビルドツールは使いません。HTML / CSS / バニラJS のみで、ファイルをそのまま GitHub Pages に置いています。

## ファイル構成

| パス | 役割 |
|---|---|
| `index.html` | ページ本体。**文章の修正はここだけ** |
| `css/style.css` | 色・余白・レイアウト |
| `js/main.js` | トップ画像の切り替え・スクロール表示・FAQ開閉・追従UI |
| **`img-src/hero/`** | **トップ画像を入れる場所。ここに画像を入れます** |
| `img/` | 実際にページが読み込む画像（自動生成。手で置かない） |
| `tools/optimize_images.py` | 素材をWeb用に軽量化し、トップのスライドを組み立てるスクリプト |
| `sitemap.xml` / `robots.txt` | 検索エンジン向け |
| `.nojekyll` | GitHub Pages の Jekyll 処理を無効化 |

## ページの構成

上から順に、ヒーロー（スライドショー）→ 大切にしていること／3つの力 →
世界観ギャラリー → 興味から始まる学び（3コース）→ パソコンスキル →
プログラミング的概念 → 通った後の未来 → 代表あいさつ →
教室のご案内（2校）→ よくあるご質問 → 無料体験 → フッター。

配色は `css/style.css` 冒頭の `:root` にまとめています。
黒 `#0A0A0C` を基調に、パンフレットのラベル色（クリムゾン `#A5133A`）と
月＝ルナを受けた金 `#C9A75C` をアクセントにしています。

## 動き（アニメーション）について

すべてCSSとバニラJSで実装しています。ライブラリは使っていません。

| 動き | 実装場所 |
|---|---|
| **トップ画像が6秒ごとにふわっと切り替わる** | `.hero__slider`。間隔は `data-interval="6000"`（ミリ秒）で変更。フェードの長さは `.js .hero__slide` の `transition` |
| トップ画像がゆっくり縮まりながら現れる | `.hero__slide` の `transform: scale(1.05)` → `scale(1)` |
| ヒーローの要素が順に浮かび上がる | `style.css` の `@keyframes rise`（CSSのみ） |
| スクロールで各ブロックが出現 | `.reveal` `.stagger` ＋ `main.js` の IntersectionObserver |
| 世界観の写真が自動で横に流れる | `@keyframes marquee`（マウスを乗せると一時停止） |
| カード類のホバーで金の枠が出る | `.course` `.campus` `.apps > li` などの `:hover` |
| ボタンのホバーで色が横から満ちる | `.btn::before` |
| ヘッダーの進捗バー・影 | `main.js` のスクロール監視 |
| スマホ下部CTA／トップへ戻るの出し入れ | 同上 |

**動きを止める配慮:**

- OSの「視差効果を減らす／アニメーションを減らす」設定（`prefers-reduced-motion`）が
  オンのときは、装飾のアニメーションをすべて止めます。
  **ただしトップ画像の切り替えは続きます**（フェードをやめて瞬時に入れ替わります）。
  切り替えまで止めると「画像が変わらない」という状態になってしまうためです
- JavaScriptが読み込めなかった場合は、4秒後に `<html>` の `js` クラスを外し、
  全内容を最初から表示された状態に戻します（`index.html` 冒頭のスクリプト）。
  そのため、動きが消えても内容が読めなくなることはありません

## ローカルで確認する

```bash
python -m http.server 8000 --directory HP
```

ブラウザで `http://localhost:8000/` を開きます。
（`index.html` をダブルクリックして直接開いても見られますが、地図の表示など一部が実環境と変わります）

## 画像はどこに入れるか

### トップの大きな画像（時間で切り替わるスライド）

**`img-src/hero/` に入れます。** ファイル名は `01_説明.jpg` の形にしてください。

```
img-src/hero/
  01_パソコンに向かう子ども.png   ← 1枚目
  02_レッスンの様子.png            ← 2枚目
  03_マインクラフトで世界をつくる.png ← 3枚目
```

入れたら `HP` フォルダで下を実行します。これだけで、軽量化・切り抜き・
`index.html` のスライド差し替えまで自動で終わります。

```bash
python tools/optimize_images.py
```

- **数字の順**に表示されます。順番を変えたいときは数字を書き換えてください
- アンダーバーより後ろの文字が画像の説明文（alt）になります
- **枚数は自由**です。1枚だけにすると切り替わらない普通の画像になります
- **横4：縦3** の枠に中央基準で切り抜かれます。人物が端に写っていると切れます
- iPhoneの `.heic` は `pip install pillow-heif` を一度実行すると使えるようになります

詳しくは [img-src/hero/README.md](img-src/hero/README.md) を見てください。

### そのほかの画像（コース紹介・代表写真・背景）

**`img-src/lib/` に入れます。** ファイル名がそのまま `img/` での名前になるので、
差し替えるときは同じ名前で上書きしてから `python tools/optimize_images.py` を実行してください。

| ファイル名 | 使われている場所 |
|---|---|
| `course-minecraft` / `course-scratch` / `course-roblox` | 3コースのカードと世界観ギャラリー |
| `pcskill` | パソコンスキルの写真 |
| `ceo` | 代表あいさつの写真 |
| `code-texture` | 無料体験セクションの背景 |
| `world-01` 〜 `world-03` | 世界観ギャラリー |
| `ig-qr.png` | フッターのQRコード（読み取り精度のため無変換でコピーされます） |

### 手で `img/` を触らないでください

`img/` はスクリプトが毎回作り直すフォルダです。ここに直接置いたファイルは
次回の実行で消えることがあります（特に `hero-*.jpg` / `hero-*.webp`）。

### 画像の出どころ

`img-src/` の画像は、2026年版の二つ折りパンフレット（Canva）から取り出したものです。
ロゴだけは `img-src/lib/_logo-source.png` に置いてあります（アンダーバー始まりのファイルは
一括変換の対象外で、ロゴ・ファビコン・OGP画像の生成にだけ使われます）。

**掲載写真について**: 実際の生徒さんが写っている写真を使う場合は、必ず保護者の方の同意を
得てから使用してください。ゲーム画面（マインクラフト・Scratch・ロブロックス）は
各社の利用規約の範囲でご利用ください。

**画像は暗くしない**: 黒背景の上で写真がしっかり見えるよう、画像には明度を下げる
フィルタをかけていません（2026-07-29にユーザー指示）。ヒーローだけは文字が乗る左側に
グラデーションの暗幕をかけていますが、右側は写真がそのまま見えるようにしています。

## 自分で微調整する

ビルド作業はありません。**メモ帳やVS Codeでファイルを保存して、ブラウザを再読み込みするだけ**で反映されます。

### 文章を直したい

`index.html` を開いて、直したい文字をそのまま書き換えます。
どこに何があるかは、ファイル内の `<!-- ===== 4. 興味から始まる学び ===== -->` のような
見出しコメントを目印にしてください。

| 直したいもの | index.html の目印 |
|---|---|
| キャッチコピー・電話番号 | `<!-- ===== 1. ヒーロー ===== -->` |
| 教室の考え方の文章 | `<!-- ===== 2. 大切にしていること ===== -->` |
| コースの説明・言語タグ | `<!-- ===== 4. 興味から始まる学び ===== -->` |
| パソコンスキル・対応ソフト | `<!-- ===== 5. パソコンスキル ===== -->` |
| プログラミング的概念の9語 | `<!-- ===== 6. プログラミング的概念 ===== -->` |
| 通った後の未来の5項目 | `<!-- ===== 7. 通った後の未来 ===== -->` |
| 代表あいさつ | `<!-- ===== 8. 代表あいさつ ===== -->` |
| 住所・地図 | `<!-- ===== 9. 教室（2校） ===== -->` |
| よくあるご質問 | `<!-- ===== 10. よくあるご質問 ===== -->` |
| 無料体験の日程・内容 | `<!-- ===== 11. 無料体験 ===== -->` |

**FAQを直したときは `<head>` 内の FAQPage 構造化データも同じ内容に直してください。**
検索結果に出る内容なので、ページと食い違うと逆効果になります。

### 色・余白・文字サイズを変えたい

`css/style.css` の**先頭にある `:root`（11行目〜）だけ**を触れば、サイト全体に反映されます。

| 変えたいもの | 行 | 現在の値 |
|---|---|---|
| 背景の黒 | `--ink` | `#0A0A0C` |
| 本文の文字色 | `--text` | `#F2F0EC` |
| 赤（ボタン・ラベル） | `--crimson` | `#A5133A` |
| 金（English見出し・枠） | `--gold` | `#C9A75C` |
| セクションの上下の余白 | `--sec-pad` | `clamp(3.5rem, 10vw, 7rem)` |
| キャッチコピーの大きさ | `--ts-display` | `clamp(2rem, 6.6vw, 4rem)` |

`clamp(最小, 画面幅に応じた値, 最大)` という書き方です。
真ん中の数字を大きくすると、画面が広いときに大きくなります。

### トップ画像の動きを変えたい

| 変えたいもの | 場所 |
|---|---|
| 切り替わる間隔 | `index.html` の `data-interval="6000"`（ミリ秒。8000にすると8秒ごと） |
| ふわっと変わる速さ | `css/style.css` の `.js .hero__slide` の `transition: opacity 1.8s ...` |
| 画像の枚数・順番・内容 | `img-src/hero/` のファイルを入れ替えて `python tools/optimize_images.py` |

### セクションの順番を入れ替えたい

`index.html` の `<section ...>` から対応する `</section>` までを、まとめて切り取って貼り直します。
見出しコメントごと動かすと分かりやすいです。丸ごと消せばそのセクションは非表示になります。

### 触らないほうがよい場所

- **`img/` フォルダ** — `python tools/optimize_images.py` が毎回作り直します。ここに直接置いたファイルは消えます
- **`<!-- HERO-SLIDES:START -->` 〜 `<!-- HERO-SLIDES:END -->`** — 同じスクリプトが自動で書き換えます
- `js/main.js` — 動きの仕組みです。触らなくても見た目の調整はできます

### 確認のしかた

`index.html` をダブルクリックすれば見られます。
ただし**地図が表示されない**ので、正確に見たいときは `HP` フォルダで下を実行し、
`http://localhost:8000/` を開いてください（止めるときは Ctrl+C）。

```bash
python -m http.server 8000
```

## GitHub Pages への公開

初回のみ:

1. github.com で `lunacaldoacademy/website` を Public・空の状態で作成
2. このフォルダで以下を実行

```bash
git init
git add .
git commit -m "ルナカルドアカデミー公式サイト 初版"
git branch -M main
git remote add origin https://github.com/lunacaldoacademy/website.git
git push -u origin main
```

3. リポジトリの **Settings → Pages** で Source を `Deploy from a branch` / `main` / `/ (root)` に設定
4. 数分後 `https://lunacaldoacademy.github.io/website/` で公開されます

2回目以降の更新:

```bash
git add . && git commit -m "内容を更新" && git push
```

独自ドメインを取得した場合は、このフォルダに `CNAME` ファイル（中身はドメイン名1行）を追加し、
`index.html` の `og:url` / `canonical`、`sitemap.xml`、`robots.txt` のURLを書き換えてください。

## よく差し替える項目

| 項目 | 差し替える場所 |
|---|---|
| トップ画像 | `img-src/hero/` に入れて `python tools/optimize_images.py`（index.htmlは自動更新） |
| 体験の日程・内容 | `<section id="trial">` の `.trial__dl` |
| よくあるご質問 | `<section id="faq">` の `<details>`。**同じ内容を `<head>` の FAQPage 構造化データにも反映すること** |
| 電話番号・メール | `tel:` / `mailto:` のリンク（ヒーロー・教室・無料体験・フッター・固定CTA）と `<head>` の構造化データ |
| 代表あいさつ | `<section id="ceo">` |
| 教室の住所・地図 | `<section id="campus">` の `.campus`（2校ぶん） |
| 作品イメージの並び | `<div class="gallery__track">`。**同じ並びを2回**書くことで途切れず流れるので、増減は必ず前半・後半の両方に反映する |

## 表現のルール（編集時に必ず守る）

パンフレット（2026年版）の表記に合わせています。

- **受講料金はサイトに一切載せない。** 金額は無料体験の場で初めてお伝えする内容です。
  入会金・授業料・初期セット費・メンテナンス費・アカウント費の金額はもちろん、
  構造化データの `priceRange` も入れないでください。
  料金を尋ねられた場合の受け皿として、FAQに「受講料金を知りたいのですが。」→
  「無料体験の際に直接ご案内しています」という項目を置いてあります

- 名乗りは **「キッズプログラミングスクール」**。キャッチコピーは **「ゲームの遊びが学びに変わる瞬間を」**
- 学べる内容は **マインクラフト / Scratch / ロブロックス** の3つ＋**パソコンスキル**
  - 旧パンフレットの「Minecraft教育版」「PC総合」という呼び方は使わない
- **「月替わり」は使わない**。「どこからでも学べる」「やりたいことから始められる」で表す
- **「わたしたち」「私たち」は使わない**。主語は「ルナカルドアカデミー」にする
- 「すごい」「天才」など大げさな表現を使わない
- カフェルナカルドの言及は **堺美原校の項目に限り**、**保護者の待ち時間の実利** と
  **防犯上の安心感** だけに使う。子どもの学習体験のメリットとしては書かない
- SNS表記は `@lunacaldo_academy` のみ（地名を併記しない）
- 無料体験の日程は **「平日16:20〜 / 18:00〜（ご希望の日時を伺います）」** で固定。
  土日開催や特定日の形式にはしない
- 2校（堺美原校・富田林喜志校）は実際にはカリキュラム・料金とも同じだが、
  サイト上は**「カリキュラムは同じ」**とだけ書く（料金に触れないため）。片方だけ有利に書かない

## 未対応・要確認

- **地図**: Googleマップの住所検索による埋め込みです。Googleビジネスプロフィールを
  作成したら、その埋め込みコードに差し替えると精度が上がります
- **富田林喜志校の最寄り駅**: 「近鉄長野線・喜志駅の周辺」と記載しています。
  徒歩分数など正確な情報が分かれば `<section id="campus">` に追記してください
- **営業時間**: パンフレットに記載がないため、構造化データに `openingHours` を入れていません
