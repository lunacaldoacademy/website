# トップ画像（スライドショー）の入れ場所

このフォルダに画像を入れて、`HP` フォルダで下のコマンドを実行すると、
トップの大きな画像が自動で入れ替わるようになります。

```bash
python tools/optimize_images.py
```

## ファイル名のつけかた

`01_説明.jpg` のように、**「数字2桁」＋「アンダーバー」＋「説明」** の形にします。

| ファイル名の例 | どうなるか |
|---|---|
| `01_パソコンに向かう子ども.jpg` | 1枚目に表示。「パソコンに向かう子ども」が画像の説明文になります |
| `02_レッスンの様子.jpg` | 2枚目に表示 |
| `03_マインクラフトで世界をつくる.jpg` | 3枚目に表示 |

- **数字の順に表示**されます。順番を変えたいときは数字を書き換えてください
- アンダーバーより後ろの文字が、画像が表示できないときの説明文（alt）と、
  目の不自由な方が使う読み上げソフトの読み上げ文になります
- 枚数は何枚でもかまいません。1枚だけにすると、切り替わらない普通の画像になります

## 使える形式

`.jpg` `.jpeg` `.png` `.webp`

**iPhoneで撮った `.heic` はそのままでは使えません。** どちらかで対応してください。

- iPhoneの「設定 → カメラ → フォーマット」を「互換性優先」にしてから撮り直す
- または一度だけ以下を実行して、HEICを読めるようにする

```bash
pip install pillow-heif
```

## 画像の形について

トップは **横4：縦3** の枠に、中央を基準に切り取って表示されます。
横長の写真がきれいに収まります。人物が端に写っていると切れることがあるので、
中央寄りに写っているものを選んでください。

## 実際の生徒さんを撮影した写真を使うとき

必ず**保護者の方の同意**を得てから使用してください。
同意書のひな型は `../../../SNS/保護者同意書_ひな型.docx` にあります。

## 元の画像はここに置いたままで大丈夫です

ここの画像はホームページには直接使われません。
`tools/optimize_images.py` が軽量化したものを `img/hero-01.webp` などとして書き出し、
ページはそちらを読み込みます。
